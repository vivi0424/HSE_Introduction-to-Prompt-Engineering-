# HSE_Introduction-to-Prompt-Engineering-
Итоговый проект по курсу "Введение в промпт-инжиниринг"
# LLM и функции Проппа

Насколько точно и стабильно большие языковые модели размечают русскую волшебную сказку по функциям действующих лиц В. Я. Проппа и помогают ли им определения функций и пример в промпте.

## Данные
- `tales/` — 12 сказок из сборника А. Н. Афанасьева (№ по Проппу; сказка 74 — перевод с украинского); 116 исключена из эксперимента.
- `propp_gold.csv` — эталон: формулы по разборам в «Морфологии сказки» (1928), выверенные вручную.

## Код
| Файл | Что делает |
|---|---|
| `propp_groq.ipynb` | сбор ответов через Groq API: gpt-oss-20b, gpt-oss-120b, Qwen 3.8 27B |
| `propp_yandex.py` | сбор ответов через Yandex AI Studio: YandexGPT 5.1, DeepSeek V4.1 Flash |
| `propp_analysis.ipynb` | метрики, статистические тесты, графики |

## Дизайн
5 моделей × 3 условия промпта (A — названия функций, B — + определения, C — + пример) × 11 сказок × 5 итераций, T = 0.7; проверка температуры (T = 0.3) на 3 сказках.

## Запуск
1. Ключи: `GROQ_API_KEY` (Groq), `YC_FOLDER_ID` и `yc init` (Yandex Cloud).
2. `propp_groq.ipynb` и `python propp_yandex.py` → ответы в `cache/*.jsonl`.
3. `propp_analysis.ipynb` → таблицы и графики в `results/`.
